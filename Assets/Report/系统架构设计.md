3.1系统架构设计
染迹项目由以下核心子系统组成：
3.1.1 TieDyeSystem子系统
TieDyeSystem子系统负责扎染图案生成、布料物理模拟和用户交互等核心功能。
主要组件：
TieDyeGenerator：扎染图案生成核心类，负责根据设计数据生成扎染纹理并应用到布料材质。
ClothPhysicsManager：布料物理管理器，负责控制布料的物理属性和模拟效果。
CanvasManager：画布管理器，负责多个画布之间的切换和动画效果。
TieDyeDataTypes：数据结构定义，包含图案线数据和设计会话数据等。
3.1.2 GameManager子系统
GameManager子系统负责整体状态管理和场景控制。
主要组件：
GameManager：游戏管理核心类，实现单例模式，负责场景加载、数据存储和管理。
SceneManager：场景管理器，负责管理场景的UI控制和交互以及动画功能。
3.1.3 ContentManagementSystem子系统
ContentManagementSystem子系统负责管理应用中的图文内容，支持多场景的内容展示。
主要组件：
ContentManager：内容管理核心类，负责加载、缓存和管理图文内容。
InteractiveContentController：交互式内容控制器，处理用户点击事件并触发相应的内容展示。
ContentDataTypes：内容数据结构定义，包含图文数据、分类信息等。
3.1.4 HistorySystem子系统
HistorySystem子系统负责展示扎染的历史文化内容。
主要组件：
HistoryContentLoader：历史内容加载器，负责加载历史相关的图文资料。
HistoryTimelineController：历史时间轴控制器，支持按时间顺序展示历史事件。
3.1.5 TechniqueSystem子系统
TechniqueSystem子系统负责展示扎染工艺技术相关内容。
主要组件：
TechniqueContentLoader：工艺内容加载器，负责加载工艺技术相关的图文资料。
TechniqueGuideController：工艺技法分类控制器，提供不同工艺技法的查看。
3.1.6 ProductSystem子系统
ProductSystem子系统负责展示扎染成品案例。
主要组件：
ProductGalleryController：产品列表控制器，管理成品展示的界面。
ProductDetailViewer：产品详情查看器，展示选中产品的详细信息。
ProductCategoryManager：产品分类管理器，支持按类别筛选和展示产品。
3.1.7 PatternSystem子系统
PatternSystem子系统负责介绍扎染纹样的特点、寓意。
主要组件：
PatternLibraryController：纹样库控制器，管理各类扎染纹样的分类和展示。
PatternDetailViewer：纹样详情查看器，展示选中纹样的详细信息。

3.2组件间关系
GameManager作为中央控制器，与所有其他子系统进行交互，负责协调各组件间的工作。
TieDyeGenerator与ClothPhysicsManager之间存在依赖关系，TieDyeGenerator生成的纹理需要通过ClothPhysicsManager应用到布料上。
ContentManager作为内容管理的核心，被HistorySystem、TechniqueSystem、ProductSystem和PatternSystem共享使用。
InteractiveContentController将在多个场景中复用，实现统一的点击展示图文内容的交互模式。
GameManager实现各个场景切换的管理和场景间数据传递。
3.3数据流
3.3.1 设计场景数据流
1. 用户通过UI界面创建或修改设计。
2. 设计数据被传递给GameManager进行存储和管理。
3. TieDyeGenerator从GameManager获取设计数据，生成扎染纹理。
4. 生成的纹理通过ClothPhysicsManager应用到布料模型上。
3.3.2 历史场景数据流
1. 用户在History场景中点击时间线事件或历史物品。
2. HistoryTimelineController捕获点击事件，并从ContentManager请求相应的内容数据。
3. ContentManager加载并返回图文内容。
4. InteractiveContentController展示加载的内容，包括图片和文字介绍。
3.3.3 技法场景数据流
1. 用户在Technique场景中选择特定工艺。
2. TechniqueStepController展示工艺步骤的图文说明。
3. ToolInteractiveController处理用户输入并更新界面反馈。
3.3.4 纹样场景数据流
1. 用户进入PatternerScene场景，PatternLibraryController加载并展示五种纹样分类。
2. 用户可以按分类筛选纹样，或直接浏览纹样库中的所有纹样。
4. PatternDetailViewer从ContentManager加载纹样的详细信息
3.3.5 产品场景数据流
1. ProductGalleryController从ContentManager加载产品数据。
2. 用户浏览产品缩略图并选择感兴趣的产品。
3. ProductDetailViewer展示产品的详细信息，包括大图和描述。
4. 用户可以通过ProductCategoryManager按类别筛选产品。

《染迹》系统采用层次化状态架构设计，从主界面跳转五个核心功能模块：历史界面、工艺界面、纹样图鉴界面、成品界面和模拟扎染界面，每个主要界面内部采用嵌套子状态结构，形成清晰的浏览层级，比如主界面的分支导航、模块内的标准流程。从主界面出发，用户可通过对应按钮单向进入任一功能模块。各模块内部保持列表→详情→返回的闭环浏览体验。
3.8.1核心状态（主要界面）
加载界面：系统启动时的初始化状态，完成资源加载后自动进入主界面
主界面：系统中心枢纽，包含五个核心功能入口
历史界面：展示扎染历史发展的时间轴和朝代信息
工艺界面：展示扎染工艺技法、制作步骤和效果说明
纹样图鉴界面：展示纹样分类体系和具体纹样信息
成品界面：展示扎染成品实物图片和应用场景
模拟扎染界面：提供互动式扎染制作体验流程
3.8.2状态嵌套（子状态）
每个主要界面内部都有子状态，形成层次结构：
（1）历史界面：
朝代列表：按时间顺序展示各历史时期
朝代详情：展示特定朝代的详细历史背景和扎染发展
（2）工艺界面：
工艺列表：展示所有扎染工艺技法的分类列表
工艺详情：展示特定工艺的详细步骤、工具和效果
（3）纹样图鉴界面：
分类列表：按几何、植物等分类展示纹样类别
纹样列表：展示特定分类下的所有纹样缩略图
纹样详情（从图鉴进入）：从图鉴页面正常浏览进入的纹样详情
（4）成品界面：
成品列表：展示不同分类扎染成品的缩略图列表
成品详情：展示单个成品的信息和应用场景
（5）模拟扎染界面：
制作纹样底稿：从可选择的花纹图案中选择或创建基础图案
染料制作过程：轻交互过程，通过切换键线性浏览染料的制作过程，辅以工具动画与特殊音效效果
面料介绍与染色处理：轻交互过程，展示不同面料特性与染色后的处理过程
成品展示：通过保存底稿设计数据在布料模型上生成相同的扎染纹理效果。
3.8.3 关键状态转换
系统启动流程：开场动画界面 → 主界面（自动转换）
主界面的分支转换：从主界面可单向跳转到五个功能模块
点击"历史发展"按钮 → 进入历史界面
点击"技法详解"按钮 → 进入工艺界面
点击"纹样图鉴"按钮 → 进入纹样图鉴界面
点击"成品展览"按钮 → 进入成品界面
点击"模拟扎染"按钮 → 进入模拟扎染界面
模块内导航：各模块内部有标准的浏览流程
历史界面：朝代列表 → 朝代详情 → 返回列表 → 返回主界面
工艺界面：工艺列表 → 工艺详情 → 返回列表 → 返回主界面
纹样图鉴界面：分类列表 → 纹样列表 → 纹样详情 → 返回列表 → 返回分类 → 返回主界面
成品界面：成品列表 → 成品详情 → 返回列表 → 返回主界面
模拟扎染界面：模拟扎染全流程
