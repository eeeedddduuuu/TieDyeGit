# TieDye项目关键算法伪码

## 1. DesignScene - 图案设计核心算法

### 1.1 图案交互管理算法

（1）UI组件结构
DesignArea：设计区域Canvas，作为所有图案的父容器；
DraggablePattern：可交互图案组件，包含Image和RectTransform；
SelectionOutline：选中效果轮廓，显示图案选中状态；
PatternContainer：图案容器，统一管理所有图案对象。

（2）交互逻辑
拖拽交互：用户鼠标按下图案，记录偏移量，拖拽过程中实时更新位置；
缩放交互：通过鼠标滚轮控制图案缩放，限制在最小/最大缩放范围；
旋转交互：通过鼠标滚轮控制图案旋转，更新图案角度；
选中交互：点击图案时显示选中轮廓，更新当前选中图案。

（3）动画效果
选中效果动画：图案选中时播放缩放动画，时长0.2秒；
动画参数：scaleDuration = 0.2f，scaleEase = Ease.OutBack。

（4）关键代码示例
```csharp
// 图案拖拽处理
private void OnDrag(PointerEventData eventData)
{
    if (!isSelected) return;
    
    Vector2 newPosition;
    RectTransformUtility.ScreenPointToLocalPointInRectangle(
        designArea, eventData.position, eventData.pressEventCamera, out newPosition);
    
    rectTransform.localPosition = newPosition - dragOffset;
}

// 图案缩放处理
private void OnScroll(PointerEventData eventData)
{
    if (!isSelected) return;
    
    float scaleFactor = Mathf.Clamp(scale + eventData.scrollDelta.y * 0.1f, minScale, maxScale);
    rectTransform.localScale = new Vector3(scaleFactor, scaleFactor, 1f);
    scale = scaleFactor;
}

// 图案选中处理
private void OnPointerDown(PointerEventData eventData)
{
    isSelected = true;
    ShowSelectionOutline();
    
    // 播放选中动画
    rectTransform.DOScale(1.1f * scale, 0.2f)
        .SetEase(Ease.OutBack)
        .OnComplete(() => {
            rectTransform.DOScale(scale, 0.2f).SetEase(Ease.OutBack);
        });
}
```

### 1.2 设计数据收集算法

（1）UI组件结构
DesignArea：设计区域，包含所有DraggablePattern对象；
CanvasDesignData：设计数据类，存储设计信息；
PatternPlacement：图案放置数据类，存储单个图案的位置、缩放等信息。

（2）交互逻辑
遍历设计区域内所有子对象；
检查是否为DraggablePattern组件；
收集每个图案的位置、缩放、旋转和图案ID；
构建完整的CanvasDesignData对象。

（3）动画效果
无

（4）关键代码示例
```csharp
// 收集设计数据的核心方法
private CanvasDesignData CollectDesignData()
{
    CanvasDesignData designData = new CanvasDesignData();
    designData.designName = "MyDesign";
    designData.createTime = DateTime.Now;
    designData.canvasSize = new Vector2(designArea.rect.width, designArea.rect.height);
    
    // 遍历设计区域内的所有图案
    foreach (Transform child in designArea.transform)
    {
        DraggablePattern pattern = child.GetComponent<DraggablePattern>();
        if (pattern != null)
        {
            PatternPlacement placement = new PatternPlacement();
            placement.patternId = pattern.PatternId;
            placement.position = pattern.rectTransform.localPosition;
            placement.scale = pattern.rectTransform.localScale.x;
            placement.rotation = pattern.rectTransform.localRotation.eulerAngles.z;
            
            designData.placements.Add(placement);
        }
    }
    
    return designData;
}
```

```csharp
            canvasGroup.DOFade(0f, 0.3f)
```

## 2. 3DScene - 3D渲染和纹理烘焙算法

### 2.1 图案在画布上的重建算法

（1）UI组件结构
PatternContainer：图案容器，用于放置重建的图案；
CanvasDesignData：设计数据类，包含图案放置信息；
patternPrefab：图案预制体，用于实例化新图案。

（2）交互逻辑
清除现有图案；
遍历设计数据中的图案放置信息；
实例化图案预制体并设置参数；
处理用户上传图片的特殊情况。

（3）动画效果
图案重建动画：图案实例化时播放淡入动画，时长0.5秒；
动画参数：fadeDuration = 0.5f，fadeEase = Ease.OutQuad。

（4）关键代码示例
```csharp
// 重建图案的核心方法
private void RebuildPatterns(CanvasDesignData designData)
{
    // 清除现有图案
    foreach (Transform child in patternContainer.transform)
    {
        Destroy(child.gameObject);
    }
    
    // 遍历图案放置信息
    for (int i = 0; i < designData.placements.Count; i++)
    {
        PatternPlacement placement = designData.placements[i];
        
        // 实例化图案预制体
        GameObject patternObj = Instantiate(patternPrefab, patternContainer);
        DraggablePattern pattern = patternObj.GetComponent<DraggablePattern>();
        
        // 设置图案参数
        pattern.rectTransform.localPosition = placement.position;
        pattern.rectTransform.localScale = new Vector3(placement.scale, placement.scale, 1f);
        pattern.rectTransform.localRotation = Quaternion.Euler(0, 0, placement.rotation);
        
        // 设置图案纹理
        Texture2D patternTexture = GetPatternTexture(placement.patternId);
        pattern.image.sprite = Sprite.Create(patternTexture, new Rect(0, 0, patternTexture.width, patternTexture.height), new Vector2(0.5f, 0.5f));
        
        // 播放淡入动画
        CanvasGroup canvasGroup = patternObj.AddComponent<CanvasGroup>();
        canvasGroup.alpha = 0f;
        
        canvasGroup.DOFade(1f, 0.5f)
            .SetEase(Ease.OutQuad)
            .SetDelay(i * 0.05f);
    }
}
```

### 2.2 纹理烘焙算法

（1）UI组件结构
BakeCanvas：烘焙用画布，包含所有图案；
BakeCamera：烘焙相机，用于渲染纹理；
ClothModel：布料3D模型，用于显示烘焙后的纹理。

（2）交互逻辑
计算烘焙纹理尺寸；
创建RenderTexture；
将画布渲染到纹理；
将烘焙后的纹理应用到布料模型。

（3）动画效果
烘焙进度动画：显示烘焙进度条，使用填充动画；
动画参数：fillDuration = 1.0f，fillEase = Ease.Linear。

（4）关键代码示例
```csharp
// 纹理烘焙的核心方法
private Texture2D BakeTexture()
{
    // 计算烘焙纹理尺寸
    int textureWidth = Mathf.RoundToInt(bakeCanvas.rect.width * resolutionScale);
    int textureHeight = Mathf.RoundToInt(bakeCanvas.rect.height * resolutionScale);
    
    // 释放之前的烘焙纹理
    if (bakedTexture != null)
    {
        Destroy(bakedTexture);
    }
    
    // 创建RenderTexture
    RenderTexture renderTexture = new RenderTexture(textureWidth, textureHeight, 24);
    renderTexture.name = "BakedTieDyeTexture";
    
    // 设置相机参数
    bakeCamera.targetTexture = renderTexture;
    bakeCamera.enabled = true;
    
    // 渲染到纹理
    bakeCamera.Render();
    
    // 读取纹理数据
    RenderTexture.active = renderTexture;
    bakedTexture = new Texture2D(textureWidth, textureHeight, TextureFormat.RGBA32, false);
    bakedTexture.ReadPixels(new Rect(0, 0, textureWidth, textureHeight), 0, 0);
    bakedTexture.Apply();
    
    // 恢复相机设置
    RenderTexture.active = null;
    bakeCamera.targetTexture = null;
    bakeCamera.enabled = false;
    
    // 应用到布料模型
    Renderer clothRenderer = clothModel.GetComponent<Renderer>();
    if (clothRenderer != null)
    {
        clothRenderer.material.mainTexture = bakedTexture;
    }
    
    // 销毁RenderTexture
    Destroy(renderTexture);
    
    return bakedTexture;
}
```

### 2.3 相机自动对齐算法

（1）UI组件结构
bakeCanvas：烘焙画布，用于计算相机位置；
bakeCamera：烘焙相机，需要自动对齐；

（2）交互逻辑
计算画布中心位置；
设置相机位置和旋转；
计算并设置正交相机参数；

（3）动画效果
无

（4）关键代码示例
```csharp
// 相机自动对齐的核心方法
private void AutoAlignCamera()
{
    if (bakeCanvas == null || bakeCamera == null)
    {
        Debug.LogError("画布或相机未设置");
        return;
    }
    
    // 计算画布中心位置
    Vector3 canvasCenter = bakeCanvas.transform.position;
    
    // 设置相机位置
    bakeCamera.transform.position = canvasCenter + new Vector3(0, 0, -50);
    bakeCamera.transform.rotation = Quaternion.Euler(0, 0, 0);
    
    // 设置正交投影参数
    bakeCamera.orthographic = true;
    float canvasWidth = bakeCanvas.rect.width * bakeCanvas.transform.lossyScale.x;
    float canvasHeight = bakeCanvas.rect.height * bakeCanvas.transform.lossyScale.y;
    
    // 计算正交大小（取宽高中较大的一半）
    float orthoSize = Mathf.Max(canvasWidth, canvasHeight) / 2f / bakeCamera.aspect;
    bakeCamera.orthographicSize = orthoSize;
    
    // 设置裁剪面
    bakeCamera.nearClipPlane = 0.1f;
    bakeCamera.farClipPlane = 100f;
}
```

## 3. UI切换动画算法

### 3.1 淡入淡出过渡算法

（1）UI组件结构
transitionCanvas：过渡画布，包含过渡Image；
transitionImage：过渡图像，用于显示过渡效果；

（2）交互逻辑
触发过渡动画；
执行淡出动画（当前场景退出）；
加载新场景；
执行淡入动画（新场景进入）；

（3）动画效果
淡入淡出动画：使用DOFade实现画布透明度变化；
动画参数：transitionDuration = 0.3f，fadeEase = Ease.Linear；

（4）关键代码示例
```csharp
// 淡入淡出过渡的核心方法
private IEnumerator PlayFadeTransition(float duration, Color color, bool isFadeIn)
{
    transitionImage.color = new Color(color.r, color.g, color.b, isFadeIn ? 1f : 0f);
    
    float elapsedTime = 0f;
    while (elapsedTime < duration)
    {
        float alpha = isFadeIn ? 1f - (elapsedTime / duration) : (elapsedTime / duration);
        transitionImage.color = new Color(color.r, color.g, color.b, alpha);
        
        elapsedTime += Time.deltaTime;
        yield return null;
    }
    
    transitionImage.color = new Color(color.r, color.g, color.b, isFadeIn ? 0f : 1f);
}

// 场景过渡的核心方法
public IEnumerator TransitionToScene(string sceneName)
{
    // 执行淡出动画
    yield return StartCoroutine(PlayFadeTransition(transitionDuration, transitionColor, false));
    
    // 加载新场景
    AsyncOperation asyncLoad = SceneManager.LoadSceneAsync(sceneName);
    asyncLoad.allowSceneActivation = false;
    
    while (asyncLoad.progress < 0.9f)
    {
        yield return null;
    }
    
    asyncLoad.allowSceneActivation = true;
    yield return null;
    
    // 执行淡入动画
    yield return StartCoroutine(PlayFadeTransition(transitionDuration, transitionColor, true));
}
```

### 3.2 擦拭效果过渡算法

（1）UI组件结构
transitionCanvas：过渡画布；
transitionImage：过渡图像；

（2）交互逻辑
初始化擦拭效果；
执行擦拭淡出动画（当前场景退出）；
加载新场景；
执行擦拭淡入动画（新场景进入）；

（3）动画效果
擦拭动画：通过改变Image的宽度实现擦拭效果；
动画参数：transitionDuration = 0.5f，wipeEase = Ease.OutQuad；

（4）关键代码示例
```csharp
// 擦拭过渡的核心方法
private IEnumerator PlayWipeTransition(float duration, TransitionDirection direction)
{
    float screenWidth = Screen.width;
    float initialWidth = direction == TransitionDirection.LeftToRight ? 0f : screenWidth;
    float targetWidth = direction == TransitionDirection.LeftToRight ? screenWidth * 2 : -screenWidth;
    
    RectTransform rectTransform = transitionImage.GetComponent<RectTransform>();
    rectTransform.sizeDelta = new Vector2(initialWidth, Screen.height);
    
    float elapsedTime = 0f;
    while (elapsedTime < duration)
    {
        float width = Mathf.Lerp(initialWidth, targetWidth, elapsedTime / duration);
        rectTransform.sizeDelta = new Vector2(width, Screen.height);
        
        elapsedTime += Time.deltaTime;
        yield return null;
    }
    
    rectTransform.sizeDelta = new Vector2(targetWidth, Screen.height);
}
```

### 3.3 扎染风格擦拭过渡算法

（1）UI组件结构

（2）交互逻辑

执行扎染淡入动画（新场景进入）；

（3）动画效果
扎染动画：使用颜色混合和透明度变化实现扎染效果；
动画参数：transitionDuration = 0.8f，tieDyeSpeed = 5.0f，tieDyeEase = Ease.InOutSine；

（4）关键代码示例
```csharp
// 扎染擦拭过渡的核心方法
private IEnumerator PlayTieDyeWipe(float duration, bool isFadeIn)
{
    float elapsedTime = 0f;
    float startAlpha = isFadeIn ? 1f : 0f;
    float endAlpha = isFadeIn ? 0f : 1f;
    
    while (elapsedTime < duration)
    {
        float progress = elapsedTime / duration;
        float alpha = Mathf.Lerp(startAlpha, endAlpha, progress);
        
        // 计算颜色混合因子
        float blendFactor = Mathf.Sin(elapsedTime * tieDyeSpeed) * 0.5f + 0.5f;
        Color blendColor = Color.Lerp(tieDyeColor1, tieDyeColor2, blendFactor);
        
        transitionImage.color = new Color(blendColor.r, blendColor.g, blendColor.b, alpha);
        
        elapsedTime += Time.deltaTime;
        yield return null;
    }
    
    transitionImage.color = new Color(tieDyeColor1.r, tieDyeColor1.g, tieDyeColor1.b, endAlpha);
}
```

```csharp
// 历史记录管理的核心方法
public List<CanvasDesignData> ManageHistory(CanvasDesignData newDesign)
{
    // 加载现有历史记录
    List<CanvasDesignData> history = LoadHistory();
    
    // 克隆新设计数据
    CanvasDesignData clonedDesign = JsonUtility.FromJson<CanvasDesignData>(JsonUtility.ToJson(newDesign));
    
    // 添加到历史记录开头
    history.Insert(0, clonedDesign);
    
    // 限制历史记录数量
    if (history.Count > maxHistoryRecords)
    {
        history = history.Take(maxHistoryRecords).ToList();
    }
    
    // 保存更新后的历史记录
    SaveHistory(history);
    
    return history;
}

// 加载历史记录
private List<CanvasDesignData> LoadHistory()
{
    List<CanvasDesignData> history = new List<CanvasDesignData>();
    
    if (PlayerPrefs.HasKey("DesignHistory"))
    {
        string json = PlayerPrefs.GetString("DesignHistory");
        HistoryWrapper wrapper = JsonUtility.FromJson<HistoryWrapper>(json);
        history = wrapper.designs;
    }
    
    return history;
}

// 保存历史记录
private void SaveHistory(List<CanvasDesignData> history)
{
    HistoryWrapper wrapper = new HistoryWrapper { designs = history };
    string json = JsonUtility.ToJson(wrapper);
    
    PlayerPrefs.SetString("DesignHistory", json);
    PlayerPrefs.Save();
}

// 历史记录包装类
[Serializable]
private class HistoryWrapper
{
    public List<CanvasDesignData> designs;
}
```

## 5. 图案效果生成算法

（1）UI组件结构
rawImage：显示图案效果的RawImage；
effectButtons：效果选择按钮组；

（2）交互逻辑
根据选择的效果类型应用不同的图像处理；
支持模糊、边缘检测、灰度、色彩调整等效果；
使用Shader处理图案；

（3）动画效果
效果切换动画：应用效果时播放抖动动画；
动画参数：shakeDuration = 0.5f，shakeEase = Ease.OutSine；

（4）关键代码示例
```csharp
// 图案效果生成的核心方法
public void ApplyEffect(EffectType effectType, float[] parameters)
{
    switch (effectType)
    {
        case EffectType.Blur:
            ApplyBlurEffect(parameters[0]);
            break;
        case EffectType.EdgeDetection:
            ApplyEdgeDetection(parameters[0], parameters[1]);
            break;
        case EffectType.Grayscale:
            ApplyGrayscaleEffect();
            break;
        case EffectType.ColorAdjustment:
            ApplyColorAdjustment(parameters[0], parameters[1], parameters[2]);
            break;
    }
    
    // 播放效果切换动画
    PlayEffectSwitchAnimation();
}

// 应用模糊效果
private void ApplyBlurEffect(float blurRadius)
{
    Material material = rawImage.material;
    material.SetFloat("_BlurRadius", blurRadius);
    material.SetInt("_EffectType", (int)EffectType.Blur);
}

// 应用边缘检测效果
private void ApplyEdgeDetection(float threshold, float edgeColor)
{
    Material material = rawImage.material;
    material.SetFloat("_EdgeThreshold", threshold);
    material.SetColor("_EdgeColor", new Color(edgeColor, edgeColor, edgeColor, 1f));
    material.SetInt("_EffectType", (int)EffectType.EdgeDetection);
}

// 播放效果切换动画
private void PlayEffectSwitchAnimation()
{
    Transform transform = rawImage.transform;
    
    transform.DOShakePosition(0.5f, 10f, 20, 90f, false, true)
        .SetEase(Ease.OutSine);
}
```
