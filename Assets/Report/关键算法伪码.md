# TieDye项目关键算法伪码

## 1. DesignScene - 图案设计核心算法

### 1.1 图案交互管理算法
```
算法: 图案交互管理
输入: 交互模式(Drag/Scale/Rotate)、用户输入事件
输出: 更新后的图案状态

1. 初始化交互环境
   - 获取图案的RectTransform和Image组件
   - 创建选择轮廓效果
   - 设置初始缩放和旋转值

2. 根据交互模式处理用户输入
   - 当模式为Drag时:
     a. 处理鼠标按下事件，记录拖拽偏移量
     b. 处理拖拽事件，更新图案位置
     c. 处理拖拽结束事件，恢复图案状态
   - 当模式为Scale时:
     a. 处理鼠标滚轮输入，计算缩放增量
     b. 应用缩放，并限制在最小/最大缩放范围内
   - 当模式为Rotate时:
     a. 处理鼠标滚轮输入，计算旋转增量
     b. 应用旋转，更新图案角度

3. 更新图案选择状态
   - 当点击图案时，设置为选中状态
   - 显示选择轮廓和缩放效果
   - 通知DesignManager更新选中图案

4. 返回更新后的图案位置、缩放和旋转数据
```

### 1.2 设计数据收集算法
```
算法: 设计数据收集
输入: 设计区域内的所有DraggablePattern对象
输出: CanvasDesignData对象

1. 创建空的CanvasDesignData对象

2. 遍历设计区域内的所有子对象
   - 检查是否为DraggablePattern组件
   - 如果是，获取其位置、缩放、旋转和图案ID
   - 创建PatternPlacement对象并添加到placements列表

3. 设置设计数据的基本信息
   - 设计名称
   - 创建时间
   - 画布尺寸

4. 返回完整的CanvasDesignData对象
```

### 1.3 设计数据保存和传输算法
```
算法: 设计数据保存和传输
输入: CanvasDesignData对象
输出: 保存结果

1. 收集当前设计数据
   - 从UI中获取所有图案的位置、缩放和旋转信息

2. 保存到本地存储
   - 使用JsonUtility将设计数据转换为JSON字符串
   - 使用PlayerPrefs存储JSON数据，键为"CurrentDesign"
   - 调用PlayerPrefs.Save()确保数据写入磁盘

3. 保存到历史记录
   - 加载现有的历史记录
   - 将当前设计添加到历史记录开头
   - 如果历史记录超过最大数量(10条)，删除最旧的记录
   - 将更新后的历史记录保存到PlayerPrefs

4. 传输到下一场景
   - 将设计数据存储在静态变量中，供下一场景访问

5. 返回保存结果
```

## 2. 3DScene - 3D渲染和纹理烘焙算法

### 2.1 图案在画布上的重建算法
```
算法: 图案重建
输入: CanvasDesignData对象
输出: 重建后的图案UI元素

1. 清除现有图案
   - 遍历patternContainer中的所有子对象
   - 销毁这些子对象

2. 遍历设计数据中的所有图案放置信息
   - 实例化图案预制体
   - 设置图案的位置、旋转和缩放
   - 根据图案ID查找对应的图案数据
   - 设置图案的精灵图片
   - 处理用户上传图片的特殊情况(限制大小)

3. 返回重建后的图案UI元素集合
```

### 2.2 纹理烘焙算法
```
算法: 纹理烘焙
输入: 画布尺寸、分辨率缩放因子
输出: 烘焙后的纹理

1. 释放之前的烘焙纹理(如果存在)

2. 计算烘焙纹理的尺寸
   - 宽度 = 画布宽度 * 分辨率缩放因子
   - 高度 = 画布高度 * 分辨率缩放因子

3. 创建新的RenderTexture
   - 设置名称为"BakedTieDyeTexture"
   - 设置宽度和高度

4. 渲染画布到纹理
   - 将烘焙相机的目标纹理设置为新创建的RenderTexture
   - 启用相机渲染
   - 调用相机渲染方法
   - 禁用相机渲染
   - 重置相机的目标纹理

5. 将烘焙后的纹理应用到布料模型
   - 查找布料对象的Renderer组件
   - 如果找到，将烘焙后的纹理设置为材质的主纹理

6. 返回烘焙后的纹理
```

### 2.3 相机自动对齐算法
```
算法: 相机自动对齐
输入: 画布RectTransform、烘焙相机
输出: 更新后的相机位置和参数

1. 检查画布和相机是否有效
   - 如果无效，返回

2. 计算画布中心位置

3. 设置相机位置
   - 相机位置 = 画布中心位置 + (0, 0, -50)
   - 设置相机旋转为(0, 0, 0)

4. 设置相机投影参数
   - 设置为正交投影
   - 计算相机的正交大小
   - 设置近裁剪面和远裁剪面

5. 返回更新后的相机参数
```

## 3. UI切换动画算法

### 3.1 淡入淡出过渡算法
```
算法: 淡入淡出过渡
输入: 过渡持续时间、过渡颜色
输出: 完成的淡入淡出动画

1. 初始化过渡状态
   - 创建过渡Canvas和Image
   - 设置初始透明度为0

2. 执行淡出动画(当前场景退出)
   - 记录开始时间
   - 循环直到动画完成:
     a. 计算当前时间与开始时间的差值
     b. 计算透明度(0到1的插值)
     c. 更新过渡Image的颜色和透明度
     d. 等待一帧
   - 设置最终透明度为1

3. 加载新场景
   - 使用异步加载方法
   - 等待场景加载到90%
   - 激活新场景

4. 执行淡入动画(新场景进入)
   - 记录开始时间
   - 循环直到动画完成:
     a. 计算当前时间与开始时间的差值
     b. 计算透明度(1到0的插值)
     c. 更新过渡Image的颜色和透明度
     d. 等待一帧
   - 设置最终透明度为0

5. 结束过渡
   - 设置过渡状态为完成
```

### 3.2 擦拭效果过渡算法
```
算法: 擦拭效果过渡
输入: 过渡持续时间、过渡方向(左到右/右到左)
输出: 完成的擦拭动画

1. 初始化过渡状态
   - 创建过渡Canvas和Image
   - 设置初始宽度为0(左到右)或屏幕宽度(右到左)

2. 执行擦拭淡出动画(当前场景退出)
   - 记录开始时间
   - 循环直到动画完成:
     a. 计算当前时间与开始时间的差值
     b. 计算宽度变化(0到屏幕宽度*2的插值)
     c. 更新过渡Image的宽度
     d. 等待一帧
   - 设置最终宽度为屏幕宽度*2

3. 加载新场景(同上)

4. 执行擦拭淡入动画(新场景进入)
   - 记录开始时间
   - 循环直到动画完成:
     a. 计算当前时间与开始时间的差值
     b. 计算宽度变化(屏幕宽度*2到0的插值)
     c. 更新过渡Image的宽度
     d. 等待一帧
   - 设置最终宽度为0

5. 结束过渡
```

### 3.3 扎染风格擦拭过渡算法
```
算法: 扎染风格擦拭过渡
输入: 过渡持续时间、颜色1、颜色2、动画曲线
输出: 完成的扎染擦拭动画

1. 初始化过渡状态
   - 创建过渡Canvas和Image
   - 设置初始透明度为0
   - 准备颜色混合参数

2. 执行扎染淡出动画(当前场景退出)
   - 记录开始时间
   - 循环直到动画完成:
     a. 计算当前时间与开始时间的差值
     b. 计算过渡进度(0到1)
     c. 计算扎染强度(使用动画曲线)
     d. 计算颜色混合因子(使用正弦函数实现颜色变化)
     e. 混合两种扎染颜色
     f. 设置过渡Image的颜色和透明度
     g. 等待一帧
   - 设置最终透明度为1

3. 加载新场景(同上)

4. 执行扎染淡入动画(新场景进入)
   - 记录开始时间
   - 循环直到动画完成:
     a. 计算当前时间与开始时间的差值
     b. 计算过渡进度(1到0)
     c. 计算扎染强度(使用动画曲线)
     d. 计算颜色混合因子(反向正弦函数)
     e. 混合两种扎染颜色
     f. 设置过渡Image的颜色和透明度
     g. 等待一帧
   - 设置最终透明度为0

5. 结束过渡
```

## 4. 数据持久化算法

### 4.1 设计数据保存算法
```
算法: 设计数据保存
输入: CanvasDesignData对象
输出: 保存结果

1. 验证输入数据
   - 检查设计数据是否有效

2. 序列化设计数据
   - 使用JsonUtility将CanvasDesignData对象转换为JSON字符串

3. 保存到本地存储
   - 使用PlayerPrefs将JSON字符串存储到"CurrentDesign"键
   - 调用PlayerPrefs.Save()确保数据写入磁盘

4. 记录保存结果
   - 输出调试信息，包括设计名称和图案数量

5. 返回保存结果
```

### 4.2 历史记录管理算法
```
算法: 历史记录管理
输入: CanvasDesignData对象
输出: 更新后的历史记录

1. 加载现有历史记录
   - 从PlayerPrefs中获取"DesignHistory"键的值
   - 如果存在，反序列化为CanvasDesignData列表
   - 如果不存在，创建空列表

2. 添加新设计到历史记录
   - 克隆当前设计数据(避免引用问题)
   - 将克隆的数据插入到历史记录列表的开头

3. 限制历史记录数量
   - 如果历史记录数量超过最大限制(10条)
   - 截取列表，只保留最新的10条记录

4. 保存更新后的历史记录
   - 将历史记录列表序列化为JSON字符串
   - 使用PlayerPrefs存储到"DesignHistory"键
   - 调用PlayerPrefs.Save()确保数据写入磁盘

5. 返回更新后的历史记录
```

## 5. 图案效果生成算法

### 5.1 图案效果生成算法
```
算法: 图案效果生成
输入: 原始图案、效果类型、效果参数
输出: 应用效果后的图案

1. 根据效果类型选择处理方法
   - 当效果为模糊时:
     a. 应用高斯模糊算法
     b. 根据模糊半径参数调整效果强度
   - 当效果为边缘检测时:
     a. 应用Sobel边缘检测算法
     b. 设置边缘颜色和阈值
   - 当效果为灰度时:
     a. 将图案转换为灰度图像
   - 当效果为色彩调整时:
     a. 调整亮度、对比度和饱和度

2. 应用效果到原始图案
   - 创建临时RenderTexture
   - 使用Shader处理原始图案
   - 读取处理后的纹理

3. 返回应用效果后的图案
```
