# TieDye项目关键算法分析

## 1. 扎染纹理生成主流程

**功能说明**：协调整个扎染纹理的生成过程，包括基础颜色应用、图案绘制、颜色渗透效果和织物柔化处理。

**伪代码**：
```
PROCEDURE GenerateTieDyeTexture()
    // 初始化最终纹理
    finalTieDyeTexture = 创建新纹理(textureSize, textureSize)
    
    // 应用基础颜色和织物纹理
    FOR 每个像素(i) IN finalTieDyeTexture
        x = i % textureSize
        y = i / textureSize
        pixelColor = ApplyFabricTexture(baseColor, x, y)
        设置像素(i)为pixelColor
    END FOR
    
    // 绘制所有设计图案
    FOR 每个图案位置(placement) IN loadedSessionData.designData.placements
        DrawPatternOnTexture(placement)
    END FOR
    
    // 应用颜色渗透效果
    IF colorBleeding > 0.01 THEN
        ApplyColorBleeding()
    END IF
    
    // 应用织物柔化效果
    ApplyFabricSoftening()
    
    // 应用纹理到材质
    finalTieDyeTexture.Apply()
END PROCEDURE
```

## 2. 颜色渗透算法

**功能说明**：模拟染料在织物上的渗透效果，使颜色边界更加自然柔和。

**伪代码**：
```
PROCEDURE ApplyColorBleeding()
    // 创建临时纹理副本
    tempTexture = 复制纹理(finalTieDyeTexture)
    
    // 遍历纹理中的每个像素
    FOR x = 1 TO textureSize - 2
        FOR y = 1 TO textureSize - 2
            // 随机决定是否应用渗透效果
            IF 随机值 > colorBleeding THEN
                CONTINUE
            END IF
            
            // 获取当前像素颜色
            currentColor = tempTexture.GetPixel(x, y)
            
            // 跳过接近黑色的区域
            IF (currentColor.r + currentColor.g + currentColor.b) < 2.5 THEN
                CONTINUE
            END IF
            
            // 随机选择一个附近像素
            dx = 随机范围(-2, 3)
            dy = 随机范围(-2, 3)
            targetX = 限制在边界内(x + dx, 0, textureSize - 1)
            targetY = 限制在边界内(y + dy, 0, textureSize - 1)
            
            // 混合颜色
            targetColor = tempTexture.GetPixel(targetX, targetY)
            blendedColor = 线性插值(targetColor, currentColor, 0.3 * dyeAbsorption)
            
            // 更新最终纹理
            finalTieDyeTexture.SetPixel(targetX, targetY, blendedColor)
        END FOR
    END FOR
    
    // 释放临时纹理
    销毁纹理(tempTexture)
END PROCEDURE
```

## 3. 图案绘制算法

**功能说明**：将设计的图案绘制到扎染纹理上，支持精确位置映射和旋转。

**伪代码**：
```
PROCEDURE DrawPatternOnTexture(placement)
    // 获取图案对应的线条纹理
    lineTexture = GetLineTextureForPattern(placement.patternId)
    IF lineTexture IS NULL THEN
        RETURN
    END IF
    
    // 计算纹理位置和大小
    IF usePreciseMapping THEN
        texturePos = ConvertToPreciseTexturePosition(placement.position)
        drawSize = CalculatePreciseDrawSize(placement.scale, lineTexture)
    ELSE
        texturePos = ConvertCanvasToTexturePosition(placement.position)
        drawSize = (200 * placement.scale.x, 200 * placement.scale.y)
    END IF
    
    // 绘制带旋转的纹理
    DrawTextureWithRotation(finalTieDyeTexture, lineTexture, texturePos, drawSize, placement.rotation)
END PROCEDURE
```

## 4. 带旋转的纹理绘制

**功能说明**：在目标纹理上绘制带有旋转角度的源纹理，支持alpha混合。

**伪代码**：
```
PROCEDURE DrawTextureWithRotation(target, source, position, size, rotation)
    // 获取源纹理像素数据
    sourcePixels = source.GetPixels()
    sourceWidth = source.width
    sourceHeight = source.height
    
    // 计算中心点和绘制范围
    center = position
    startX = 最大(0, 取整(center.x - size.x / 2))
    endX = 最小(target.width, 取整(center.x + size.x / 2))
    startY = 最大(0, 取整(center.y - size.y / 2))
    endY = 最小(target.height, 取整(center.y + size.y / 2))
    
    // 遍历目标纹理的绘制区域
    FOR x = startX TO endX - 1
        FOR y = startY TO endY - 1
            // 计算局部坐标
            localPos = (x - center.x, y - center.y)
            sourceUV = localPos
            
            // 应用旋转
            IF |rotation| > 0.1 THEN
                sourceUV = RotatePoint(localPos, -rotation)
            END IF
            
            // 转换为UV坐标
            u = (sourceUV.x / size.x) + 0.5
            v = (sourceUV.y / size.y) + 0.5
            
            // 检查UV坐标是否有效
            IF u >= 0 AND u <= 1 AND v >= 0 AND v <= 1 THEN
                // 获取源纹理像素颜色
                sourceX = 取整(u * sourceWidth)
                sourceY = 取整(v * sourceHeight)
                sourceX = 限制在边界内(sourceX, 0, sourceWidth - 1)
                sourceY = 限制在边界内(sourceY, 0, sourceHeight - 1)
                sourceColor = sourcePixels[sourceY * sourceWidth + sourceX]
                
                // 应用alpha混合
                IF sourceColor.a > 0.1 THEN
                    currentColor = target.GetPixel(x, y)
                    blendFactor = sourceColor.a * (1 - dyeAbsorption * 0.3)
                    newColor = 线性插值(currentColor, dyeColor, blendFactor)
                    newColor = ApplyDyeTextureDetail(newColor, x, y)
                    target.SetPixel(x, y, newColor)
                END IF
            END IF
        END FOR
    END FOR
END PROCEDURE
```

## 5. 织物纹理应用

**功能说明**：在基础颜色上应用织物纹理和编织效果，增强真实感。

**伪代码**：
```
FUNCTION ApplyFabricTexture(baseColor, x, y) RETURNS Color
    result = baseColor
    
    // 应用布料基础纹理
    IF clothBaseTexture IS NOT NULL THEN
        u = x / textureSize
        v = y / textureSize
        clothColor = clothBaseTexture.GetPixelBilinear(u * 4, v * 4)
        result = 线性插值(baseColor, clothColor * baseColor, clothTextureBlend)
    END IF
    
    // 应用织物编织纹理
    IF enableFabricWeave AND fabricWeaveTexture IS NOT NULL THEN
        u = x / textureSize * weaveScale.x
        v = y / textureSize * weaveScale.y
        weaveColor = fabricWeaveTexture.GetPixelBilinear(u, v)
        weaveInfluence = 线性插值(0.1, 0.3, fabricTextureDetail)
        result = result * 线性插值(白色, weaveColor, weaveInfluence)
    END IF
    
    RETURN result
END FUNCTION
```

## 6. 织物柔化算法

**功能说明**：模拟织物的柔和特性，调整颜色饱和度和对比度，使纹理更加自然。

**伪代码**：
```
PROCEDURE ApplyFabricSoftening()
    IF fabricSoftness < 0.01 THEN
        RETURN
    END IF
    
    // 获取所有像素
    pixels = finalTieDyeTexture.GetPixels()
    
    // 遍历所有像素
    FOR i = 0 TO pixels.Length - 1
        // 轻微降低颜色饱和度
        pixels[i] = 线性插值(pixels[i], (0.5, 0.5, 0.5), fabricSoftness * 0.1)
        
        // 增加颜色均匀性
        intensity = (pixels[i].r + pixels[i].g + pixels[i].b) / 3
        pixels[i] = 线性插值(pixels[i], (intensity, intensity, intensity), fabricSoftness * 0.2)
    END FOR
    
    // 更新纹理
    finalTieDyeTexture.SetPixels(pixels)
END PROCEDURE
```

## 7. 织物编织纹理生成

**功能说明**：生成织物编织图案的纹理，模拟真实织物的经纬线效果。

**伪代码**：
```
PROCEDURE GenerateFabricWeaveTexture()
    IF NOT enableFabricWeave THEN
        RETURN
    END IF
    
    // 初始化编织纹理
    weaveSize = 256
    fabricWeaveTexture = 创建新纹理(weaveSize, weaveSize)
    
    // 生成编织图案
    FOR x = 0 TO weaveSize - 1
        FOR y = 0 TO weaveSize - 1
            // 计算编织图案
            u = x / weaveSize * weaveScale.x
            v = y / weaveSize * weaveScale.y
            weave = Sin(u * π * 2) * Sin(v * π * 2)
            weave = Abs(weave)
            
            // 添加噪声变化
            noise = PerlinNoise(u * 8, v * 8) * 0.2
            weave = 限制在0-1之间(weave + noise)
            
            // 设置像素颜色
            weaveColor = (weave, weave, weave, 1)
            fabricWeaveTexture.SetPixel(x, y, weaveColor)
        END FOR
    END FOR
    
    // 应用纹理
    fabricWeaveTexture.Apply()
END PROCEDURE
```

## 8. 图案位置精确映射

**功能说明**：将设计画布上的图案位置精确映射到生成的纹理上，确保图案比例正确。

**伪代码**：
```
FUNCTION ConvertToPreciseTexturePosition(designPosition) RETURNS Vector2
    canvasSize = loadedSessionData.canvasSize
    
    // 将设计位置转换为0-1范围的UV坐标
    u = (designPosition.x + canvasSize.x / 2) / canvasSize.x
    v = (designPosition.y + canvasSize.y / 2) / canvasSize.y
    
    // 确保UV坐标在0-1范围内
    u = 限制在0-1之间(u)
    v = 限制在0-1之间(v)
    
    // 转换为纹理像素位置
    RETURN (u * textureSize, v * textureSize)
END FUNCTION

FUNCTION CalculatePreciseDrawSize(designScale, sourceTexture) RETURNS Vector2
    canvasSize = loadedSessionData.canvasSize
    
    // 计算设计空间中的像素尺寸
    designPixelWidth = sourceTexture.width * designScale.x
    designPixelHeight = sourceTexture.height * designScale.y
    
    // 计算纹理空间中的尺寸比例
    widthRatio = designPixelWidth / canvasSize.x
    heightRatio = designPixelHeight / canvasSize.y
    
    // 计算纹理空间中的实际尺寸
    textureWidth = widthRatio * textureSize * patternScaleFactor
    textureHeight = heightRatio * textureSize * patternScaleFactor
    
    RETURN (textureWidth, textureHeight)
END FUNCTION
```

## 9. 场景过渡效果算法

**功能说明**：实现带有扎染风格的场景过渡效果，包括颜色混合和动画曲线控制。

**伪代码**：
```
PROCEDURE PlayTieDyeWipeEffect()
    IF NOT useTieDyeEffect THEN
        // 播放普通淡入效果
        PlayNormalFadeEffect()
        RETURN
    END IF
    
    tieDyeTime = 0
    
    // 播放扎染擦拭效果
    WHILE tieDyeTime < transitionDuration
        // 计算进度和强度
        progress = tieDyeTime / transitionDuration
        intensity = tieDyeIntensityCurve.Evaluate(progress)
        
        // 创建扎染效果的混合颜色
        blendFactor = Sin(tieDyeTime * tieDyeSpeed) * 0.5 + 0.5
        blendColor = 线性插值(tieDyeColor1, tieDyeColor2, blendFactor)
        blendColor.a = 线性插值(0, 1, progress)
        
        // 更新过渡图像颜色
        transitionImage.color = blendColor
        
        // 更新时间
        tieDyeTime = tieDyeTime + Time.deltaTime
        等待下一帧
    END WHILE
END PROCEDURE
```

## 10. UI动画控制算法

**功能说明**：控制UI元素的渐显、位移动画，实现流畅的用户界面交互效果。

**伪代码**：
```
PROCEDURE PlaySequenceFadeInElements()
    // 播放板蓝根渐显动画
    PlayBanlanAnimation(0)
    等待(delayBetweenElements)
    
    // 播放石灰渐显动画
    PlayLimeAnimation(delayBetweenElements)
    等待(delayBetweenElements)
    
    // 播放原材料介绍渐显动画
    PlayRawmaterialsAnimation(delayBetweenElements * 2)
END PROCEDURE

PROCEDURE PlayElementFadeAnimation(element, delay)
    // 设置元素可见
    设置组件可见性(element.images, true)
    
    // 使用DOTween进行位移动画
    element.transform.DOAnchorPosX(0, fadeInDuration)
        .SetDelay(delay)
        .SetEase(fadeEase)
    
    // 为所有子图片组件添加渐显效果
    FOR 每个图片(image) IN element.images
        image.DOFade(1, fadeInDuration)
            .SetDelay(delay)
            .SetEase(fadeEase)
    END FOR
END PROCEDURE
```
