# TieDye项目运行报告

## 1. 项目概述

TieDye是一款基于Unity引擎开发的扎染设计与展示应用，用户可以通过该应用创建个性化的扎染图案，在3D环境中实时预览效果，并保存和分享自己的设计作品。项目采用分层架构设计，包含游戏管理层、设计系统层、3D渲染层、数据传输层和数据持久化层，各层之间职责明确，协同工作，为用户提供流畅的设计体验。

## 2. 项目结构

项目采用清晰的目录结构，便于代码管理和维护：

### 2.2 系统架构

项目采用分层架构设计，各层之间通过接口进行通信，提高了系统的可扩展性和可维护性：

1. **游戏管理层**：负责全局游戏状态管理和场景切换
2. **设计系统层**：实现图案设计、编辑和交互功能
3. **3D渲染层**：负责3D模型渲染和纹理烘焙
4. **数据传输层**：实现场景间的数据传递
5. **数据持久化层**：负责设计数据的保存和加载

## 3. 场景功能描述

### 3.1 MainMenuScene - 主菜单场景

**功能**：提供应用的主要入口，用户可以选择不同的功能模块。

**主要组件**：
- 主菜单UI：包含各种功能按钮
- 背景动画：展示扎染效果的背景动画
- 音效管理：背景音乐和音效控制

### 3.2 DesignScene - 图案设计场景

**功能**：用户可以在这里创建和编辑扎染图案。

**主要组件**：
- DesignManager：设计管理核心类，负责图案的创建、编辑和管理
- DraggablePattern：可拖拽的图案组件，支持拖拽、缩放和旋转操作
- ToolbarManager：工具栏管理器，提供各种编辑工具
- TransformGizmoController：变换控制器，用于精确调整图案的位置、缩放和旋转

**用户操作流程**：
1. 从左侧图案库选择图案
2. 将图案拖拽到设计区域
3. 使用工具栏工具调整图案的位置、缩放和旋转
4. 点击下一步按钮进入3D场景预览

### 3.3 3DScene - 3D预览场景

**功能**：将用户设计的2D图案应用到3D布料模型上，提供实时预览效果。

**主要组件**：
- PatternTextureBaker：纹理烘焙器，将2D设计转换为3D纹理
- TieDyeColorController：扎染颜色控制器，调整布料的颜色效果
- ImageSaver：图片保存器，用于保存3D预览结果

**核心算法**：
1. 纹理烘焙算法：将2D设计渲染到纹理并应用到3D模型
2. 相机自动对齐算法：确保相机能够完整捕捉设计内容

### 3.4 Process.unity - 工艺展示场景

**功能**：展示扎染工艺的制作过程，提供教育和参考价值。

**主要组件**：
- 工艺步骤展示：分步骤展示扎染制作过程
- 交互元素：允许用户控制工艺步骤的播放

### 3.5 History.unity - 历史记录场景

**功能**：展示用户保存的历史设计记录，允许用户查看和管理历史作品。

**主要组件**：
- 历史记录列表：展示所有保存的设计记录
- 设计预览：点击历史记录可以预览设计效果
- 操作按钮：提供删除、编辑等操作功能

## 4. 核心系统组件

### 4.1 DesignManager - 设计管理系统

**功能**：负责管理整个设计过程，包括图案的创建、编辑、删除和保存。

**核心方法**：
- OnPatternSelected：处理图案选择事件
- SelectPattern：选择图案并更新UI状态
- SetCurrentMode：设置当前交互模式
- DeleteSelectedPattern：删除选中的图案
- CollectDesignData：收集设计数据
- SaveAndProceed：保存设计并进入下一环节

### 4.2 DraggablePattern - 可交互图案系统

**功能**：实现图案的拖拽、缩放和旋转功能，支持多种交互模式。

**核心方法**：
- OnBeginDrag：处理拖拽开始事件
- OnDrag：处理拖拽过程事件
- OnEndDrag：处理拖拽结束事件
- ScalePattern：缩放图案
- RotatePattern：旋转图案
- GetPlacementData：获取图案的位置、缩放和旋转数据

### 4.3 SceneTransitionManager - 场景过渡系统

**功能**：实现场景间的平滑过渡动画，支持多种过渡效果。

**核心方法**：
- LoadScene：加载指定场景并应用过渡动画
- TransitionToScene：过渡到新场景的协程
- PlayTransitionOut：播放过渡淡出动画
- PlayTransitionIn：播放过渡淡入动画

### 4.4 DesignSaveManager - 数据持久化系统

**功能**：负责设计数据的保存和加载，使用PlayerPrefs进行本地存储。

**核心方法**：
- SaveDesign：保存当前设计
- LoadDesign：加载当前设计
- SaveToHistory：保存到历史记录
- LoadHistory：加载历史记录

## 5. 用户工作流程

### 5.1 图案设计流程

1. **启动应用**：用户启动TieDye应用，进入主菜单场景
2. **选择功能**：在主菜单选择"创建设计"功能
3. **进入设计场景**：系统加载DesignScene场景
4. **选择图案**：用户从左侧图案库选择喜欢的图案
5. **放置图案**：将选择的图案拖拽到设计区域
6. **调整图案**：使用工具栏工具调整图案的位置、缩放和旋转
7. **添加更多图案**：重复步骤4-6，添加更多图案到设计区域
8. **保存设计**：点击"下一步"按钮，保存当前设计
9. **进入3D预览**：系统加载3DScene场景，展示3D效果
10. **调整3D效果**：用户可以调整布料的颜色和材质效果
11. **保存结果**：保存3D预览结果或返回设计场景继续编辑

### 5.2 历史记录管理流程

1. **进入历史记录**：在主菜单选择"历史记录"功能
2. **浏览历史设计**：系统加载History场景，展示所有保存的设计
3. **选择设计**：用户点击某个历史设计进行查看
4. **预览设计**：系统加载该设计的预览效果
5. **操作设计**：用户可以选择编辑、删除或重新生成3D效果

## 6. 关键算法

### 6.1 图案交互算法

**功能**：处理用户与图案的交互操作，包括拖拽、缩放和旋转。

**核心逻辑**：
1. 根据当前交互模式处理用户输入
2. 使用插值算法实现平滑的位置、缩放和旋转变化
3. 限制交互范围，确保图案不会超出合理范围
4. 维护图案的选中状态和视觉反馈

### 6.2 纹理烘焙算法

**功能**：将2D设计转换为3D纹理并应用到布料模型上。

**核心逻辑**：
1. 在离屏Canvas上重建用户的2D设计
2. 使用相机将Canvas内容渲染到RenderTexture
3. 将RenderTexture应用到3D布料模型的材质上
4. 调整相机位置，确保完整捕捉设计内容

### 6.3 UI切换动画算法

**功能**：实现场景间的平滑过渡动画，包括淡入淡出、擦拭和扎染风格效果。

**核心逻辑**：
1. 使用协程控制动画的时间进度
2. 使用插值算法实现平滑的透明度、位置和颜色变化
3. 结合正弦函数实现扎染效果的颜色交替变化
4. 异步加载场景，确保动画流畅不卡顿

### 6.4 数据持久化算法

**功能**：将用户设计数据保存到本地存储并加载。

**核心逻辑**：
1. 使用JsonUtility将设计数据序列化为JSON字符串
2. 使用PlayerPrefs将JSON字符串保存到本地存储
3. 加载时将JSON字符串反序列化为设计数据对象
4. 管理历史记录，限制记录数量，避免存储空间过度占用

## 7. 性能考虑

### 7.1 资源管理

- **纹理资源**：使用合适的纹理尺寸和格式，避免不必要的内存占用
- **预制体**：复用预制体，减少内存开销
- **对象池**：对于频繁创建和销毁的对象，考虑使用对象池技术

### 7.2 渲染优化

- **批处理**：合并相同材质的对象，减少Draw Call
- **LOD**：对于3D模型，使用LOD技术优化渲染性能
- **遮挡剔除**：启用遮挡剔除，减少不可见对象的渲染

### 7.3 内存优化

- **资源卸载**：及时卸载不再使用的资源
- **数据压缩**：对保存的数据进行压缩，减少存储空间占用
- **内存监控**：定期监控内存使用情况，避免内存泄漏

TieDye项目采用了先进的设计理念和技术实现，为用户提供了一个直观、易用的扎染设计平台。项目的分层架构设计、清晰的组件职责、流畅的动画效果和稳定的性能表现，都体现了良好的软件工程实践。
